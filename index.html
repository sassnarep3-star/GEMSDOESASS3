Why did GEMSDOE32 (0.2778) score highest? (analysis)

The official rule is that pixels on known USGS/INGENIOUS faults are masked and excluded from scoring (DrivenData forum, staff reply). That makes off-catalogue placement the only useful place for a prediction. The repo's audit reports that this raster has 37,654 dots, 0 on the catalogue and 0 in the 2-px collar. That is consistent with a catalogue-aware design, but the catalogue layer is not in this workspace, so the figure is not re-verified here. A projection in the nine-site audit (0.286) is a model estimate, not a score. Nothing here shows that a new file will beat 0.2778.
