## Frozen requirements for any subsequent assigned lane

1. Restore the **shared** cached feature stack and the exact template evaluator/writer; do not derive catalogue features using withheld faults or substitute a private evaluator.
2. Preflight the literal all-entry registry and budget. A smaller budget does not establish uniqueness; do not target holes in a space-filling registry raster.
3. Test each input feature alone (including both AUC directions); any AUC above 0.90 is a leakage alarm. Hide entire buffered segments; derive all catalogue features from visible segments, mask visible pixels exactly, and compute pooled α=0.2, β=0.8, 300 m triangular-kernel DTI with matched baseline and paired spatial-bootstrap 95% CI.
4. Test every registered raster against the surface *before placement*, then against the final support; any rank correlation >0.90 or directed 3-pixel overlap >70% stops the run.
5. Package only using the shared writer, validate the reopened exact bytes, and run a separate quota-aware selector. Never infer a leaderboard score from a holdout metric without a validated calibration.
