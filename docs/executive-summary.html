Limitations

  • Every score in the corpus is OWNER-REPORT. Nothing here is organizer-confirmed except the two leaderboard numbers quoted above.
  • The corpus is redundant: 182 scored files collapse into 64 near-duplicate families, and the top 20 rows are about 8 distinct fields published ~2.5 times each. The effective sample size is far below 182.
  • This candidate redistributes recall that already exists in the corpus; it does not create new recall. If the hidden truth contains a structure no published raster touches, this file scores near zero on it. Hypotheses H1–H5 in hypotheses-20261031.md are aimed at exactly that, and none of them has been run.
  • N = |G| (the number of new-fault pixels, normalised) is bounded to 8,222 ≤ N ≤ 12,366 by two independent arguments; the candidate uses N = 12 000, the top of that range.
