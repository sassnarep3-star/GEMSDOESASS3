What this project is

Ninety-plus sibling repositories (GEMSDOE24, GEMSDOE25, …GEMSDOE92, this one) all attack the same DrivenData DOE-GEMS "New Faults" task with the same 19-band GeoDAWN stack and no access to the labels. Each publishes its rasters and its own score table on GitHub Pages. This repository is the meta-layer: it clones every sibling's docs/downloads, builds one registry of 1,987 rasters (1,981 grid-valid, 182 carrying an owner-reported score), and inverts the published scores to reconstruct the hidden credit field the teams were all aiming at.

The reconstruction is a weighted sum of published rasters, q(x) = max(0, Σ λ_j p_j(x)), with λ solved from the normal equations G λ = A where G_ij = Σ_x p_i p_j is the pairwise dot overlap and A_i = s_i (0.2 D_i + 0.8 N) is the kernel credit each file's score implies. The Gram matrix is what makes this different from a plain average: duplicated publications — the champion is published in four repositories under three names — are divided out rather than counted twice. 60 000 dots are then emitted by descending-q non-maximum suppression at 3 px spacing.
