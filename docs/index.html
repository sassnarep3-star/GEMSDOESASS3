What this release establishes

QuestionAnswer, with the evidence behind it
Which of the nine focus sites scored highest?GEMSDOE32, file gemsdoe32-h33-h33-2-b2-…-e5eb6e7e-zeros.tif, OWNER-REPORT 0.2778. The nine "best" files are one dot field thinned differently (88–100% mutual dot overlap).
Why did it score highest?It is the sparsest member of a single family, so it pays the least false-positive mass (α = 0.2) for the same coverage. Its score requires an enrichment of 4.1–5.3× over area-proportional placement; the catalogue holdout shows the field itself has ε = 0.13, so the enrichment most likely comes from the scored subset being fault-dense, not from the field's skill.
Can a blind field do better?No: with no enrichment the exact metric caps any dot field at ≈0.041 regardless of dot count. Beating 0.2778 needs real structure, which needs the login-walled feature stack.
Where does that leave the leaderboard?The live leaderboard fetched on 2026-10-30 shows #1 xiaofanhu 0.4544, then 0.3916, 0.3911, 0.3841. The 0.244–0.278 band of the nine focus sites is a different regime: consistent with an unsaturated, unskilled field rather than a supervised model.
What is new here?A measured DTI score model (E1/E2 experiments, spatially blocked, exact metric), a per-file measurement of all nine focus fields, and a unique candidate that passes every gate this workspace can run.

Known anomaly (IR-SASS3-90), disclosed not hidden

The 13GEMSDOE calibration lattice is a synthetic halo surface (206,895 positive cells, 4.0% of the footprint) that places a dot within 3 px of every footprint cell. The literal forward lane rule — ">70% of my dots within 3 px of any one registry raster" — is therefore ~100% for any field that predicts anywhere inside the footprint, including this release. The reverse reading (17.2% of the lattice's dots are within 3 px of mine) and the rank correlation (−0.004) show the released file is not that field, and the same forward test against the eleven real submitted fields tops out at 26.4%. The rule is flagged for an owner decision rather than worked around.
