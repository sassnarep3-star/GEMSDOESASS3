How to submit when a candidate passes

  1. Run the complete, fold-honest evaluator and feature canaries; report version, withheld count and spatial-block confidence intervals. Beat the current holdout best without using a weekly slot.
  2. Check surface rank correlation and final dot overlap against every accessible registry raster, with no exclusions; fail closed for incomplete coverage. Private or unlinked submissions cannot be ruled out.
  3. Validate a single-band GeoTIFF against the official example: CRS, shape, transform and finite [0,1] values. Generate a distinct filename and short note.
  4. Only a separate selector may promote a passing candidate. Check the actual weekly cap on the competition page, then upload the file using New submission. The archive linked above does not qualify.
