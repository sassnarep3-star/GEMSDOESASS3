## H1 protocol before any candidate placement

1. Restore the shared template's hash-pinned cached feature stack and reference data if possible; all mirrors are third-party until independently matched to an organizer download.
2. Use the shared `gems57.spatial.folds` whole-component, label-blind blocked folds, buffer and `gems57.evaluate_holdout` pooled DTI, with every catalogue-derived feature computed only from fold-visible faults. Pixel-exactly mask visible faults. Feature-only holdout AUC above 0.90 is an unresolved leakage canary, not a win.
3. Before dot placement compare the actual proposed continuous field to registry rasters by Spearman rank correlation; compare the candidate support to their three-pixel halos using the shared literal definition. If either threshold is exceeded, record the comparison and STOP: do not tune away the failure, place dots, or fabricate a submission. Missing or inaccessible registry entries cannot establish uniqueness.
4. Only if the surface passes, emit a genuinely new raster, check the final dots again against the whole specified registry, evaluate with the shared holdout including a paired spatial-block CI, and use the shared submission writer. The output remains research-only until it beats a same-evaluator, same-fold current holdout-best and a separate selector authorizes a slot.
5. Report the public leaderboard only as an official, timestamped public observation; report named historical file scores as user claims unless a submission-page receipt ties the exact hash to the organizer's score.

## Official sources supporting the questions, not proving our new algorithm

- [USGS aeromagnetic survey of Amargosa Desert](https://pubs.usgs.gov/of/2000/of00-188/of00-188.pdf): faulted volcanic units can create magnetic lineaments, while non-fault alternatives also exist.
- [USGS: Aeromagnetic expression of faults that offset basin fill](https://www.usgs.gov/publications/aeromagnetic-expression-faults-offset-basin-fill-albuquerque-basin-new-mexico): faults in sediment-filled basins can have magnetic expression.
- [USGS blind geothermal play-fairway study](https://www.usgs.gov/publications/discovering-blind-geothermal-systems-great-basin-region-integrated-geologic-and): blind systems may lack surface thermal manifestations; several data types were combined in investigated examples.
- [USGS GeoDAWN release](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and): survey scope and data descriptions.
- [DrivenData problem, metric and format](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/) and [organizer's exact known-fault mask](https://community.drivendata.org/t/scoring-clarification-are-known-usgs-ingenious-faults-masked-when-scoring-and-are-they-in-the-final-round-label-set/11516/4).
